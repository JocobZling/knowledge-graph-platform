## 2. AI / 大模型 Top News
### 2.1 CodeQL 2.27.4改进Java日志与路径注入分析
**主体：GitHub｜2026-11-04｜新颖度5/5｜正式版本更新。** [官方公告](https://github.blog/changelog/2026-11-04-codeql-2-27-4-improves-accuracy-and-query-metadata/)。
`java/log-injection`识别JDK、Apache Commons Lang/Text、Guava、OWASP Java Encoder和Spring Framework中的更多清洗器与守卫；路径注入查询增加对Commons Lang、Guava部分字符串操作的识别。这有助于降低误报，**不意味着日志注入风险自动消失**。对日志脱敏检测平台，可建立“合法清洗前后”的回归样本，避免以误报率下降代替漏报验证。

### 2.2 CodeQL pack发布增加符号链接边界检查
**主体：GitHub｜2026-11-04｜新颖度4/5｜安全加固。** [官方公告](https://github.blog/changelog/2026-11-04-codeql-2-27-4-improves-accuracy-and-query-metadata/)。
CLI在bundle/publish pack时检查符号链接解析后的路径是否仍位于pack根目录，越界文件被排除并警告；JVM告警改写stderr，避免污染JSON输出。**启发：** Skill、规则包、扫描结果生成器也应验证归档边界与机器可读输出完整性。这是CodeQL包工具的改进，不应夸大为通用MCP沙箱。

### 2.3 Copilot进入Xcode内置Coding Assistant公开预览
**主体：GitHub｜2026-11-04｜新颖度4/5｜Public Preview。** [官方公告](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant/)。
从Xcode 27.3 beta开始可直接在原生Coding Assistant中使用Copilot；要求macOS Tahoe 26.6及以上，既有Xcode扩展仍是独立选项。**边界：** 不是GA，也不适用于当前Windows/Java开发环境；其价值在于Agent能力通过宿主IDE原生入口交付，并保留用户可审阅的工作流。

## 5. Agent Ecosystem
**5.1 Skill / MCP供应链：** CodeQL pack的根目录边界检查提示：发布可执行配置或规则包时，必须检查路径解析、来源和内容完整性。安装完整性不等于运行时授权。
**5.2 Tool Calling / Workflow：** BYOK可见性说明模型来源需要与业务调用Trace关联；但GitHub客户端统计不能替代服务端真实审计，尤其在遥测关闭时。
**5.3 Browser/Coding Agent：** Xcode原生集成体现Agent逐渐融入IDE，但Browser Agent仍需独立核验页面动作、接口返回、权限和数据库结果。
**本周最值得体验：** 使用脱敏Java样例比较“真实日志注入”与“已正确清洗”的静态扫描结果，并人工复核。
**Agent 实践启发：** 将“扫描器报告”“模型报告”“可信业务回读”分成不同证据等级。

## 9. 今日实战
为日志脱敏检测平台增加“规则升级差异验收”记录：`rule_version`、`prompt_version`、`sample_id`、`expected_risk`、`actual_risk`、`false_positive`、`false_negative`、`reviewer`。对AI精筛还应记录上下文截取范围，避免将模型输出当成真实标签。

## 10. Today Worth Thinking
**扫描器误报减少了20%，但漏报增加了1条高风险敏感日志，能称为质量提升吗？** 需要同时比较Precision、Recall、关键风险漏报和人工复核成本，不能只优化单项指标。

## 11. 30分钟 Action
0—10分钟准备6条脱敏Java日志样例：真实敏感值2条、已脱敏2条、拼接与换行绕过2条；10—20分钟运行现有规则或Mock检测；20—30分钟对照人工标签记录TP/FP/FN/TN。**完成标准：** 每条有证据、版本和PASS/FAIL；任何高风险FN单独登记。

## 13. 我的备注
**测试经理智能助手：** 维持Vue3 iframe + Dify Chatflow + DeepSeek V4 + Java Capability API + PostgreSQL。把模型调用来源、Capability、权限判断、数据时间戳和Verifier结果绑定同一Trace；不要因Xcode集成更换框架。
**日志脱敏检测平台：** 对正则/Key-Value/AI精筛三类判定建立分层Golden Set，升级时同时审查误报与漏报；继续扫描和失败重扫保持`execution_epoch`隔离与回调幂等。
**Agent Testing：** 建议跟踪`Critical False Negative`、`Tool Authorization Accuracy`、`Model Source Coverage`和`Claim–Effect Consistency`。**结论：** 可信Agent依赖可解释的安全检测、可追溯的模型调用和独立业务验证。
