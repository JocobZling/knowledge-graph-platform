# AI 与 Agent 每日简报 v2｜2026-11-12

**主题：Agent评估与开发流程从框架绑定走向统一Trace、可比较实验和快速反馈。**  
**资讯窗口：优先2026-11-11，少量未报道信息回溯至11-10。**

**去重说明：** 已读取仓库2026-11-05至11-11七篇ai-tech日报；排除CodeQL、AgentCore Web Answer、GPT-6 Cyber、BioBasicsBench、Taxbit、Capability Registry、Copilot新模型、Actions日志扫描等已报主题。UAEF、AgentCore Web Search API、AI-PDLC与AWS Emulator均为11月11日新披露的独立内容。没有将新架构文章包装为基础模型首发。未确认独立主题索引存在，以七篇正文为去重依据。

## 1. 今日摘要
1. **UAEF（AWS，11/11）**：开源跨框架Agent评估方案，统一AgentTrace，36项指标覆盖7维度，支持基线对比和回归发现。
2. **AgentCore Web Search API（AWS，11/11）**：不经Gateway/MCP配置即可通过API获取搜索结果；与此前报道的Web Answer是不同的调用入口与产品能力。
3. **AI-PDLC（AWS，11/11）**：六个Agent协作完成需求发现、决策、设计与原型，人工审批控制阶段推进。
4. **AWS Emulator（AWS，11/11）**：面向AWS API的本地模拟环境，为Coding Agent提供无需创建云资源的快速反馈；模拟通过不等于云上验收通过。

**判断：** 当前智能测试助手的优先工作是统一执行轨迹和验收集，而非引入更多Agent框架。

## 2. AI/大模型 Top News
### 2.1 UAEF：跨框架Agent闭环评估
**AWS｜2026-11-11｜新颖度5/5｜新开源框架/技术文章。** [官方](https://aws.amazon.com/blogs/machine-learning/uaef-a-framework-agnostic-system-for-closed-loop-evaluation-of-ai-agents/) · [代码](https://github.com/awslabs/uaef)。

UAEF将LangGraph、LangChain、Strands、AgentCore、Langfuse及通用JSON的原始执行记录转换为统一AgentTrace；提供工具调用、回答质量、Responsible AI、性能、多轮、多Agent和推理七个维度共36项内置指标。支持确定性断言与LLM-as-a-judge、实验版本基线、差异报告；AWS称来自电信、医疗、金融的12个组织使用该框架。**限制：** 评估模型给出的分数不是业务授权判定；LLM评审输入需视为不可信，PII需脱敏。云端持久化依赖DynamoDB/S3，内网可先借鉴Schema与确定性指标而不引入AWS。
### 2.2 AgentCore Web Search API：直接检索接口
**AWS｜2026-11-11｜新颖度5/5｜新API。** [官方](https://aws.amazon.com/blogs/machine-learning/introducing-the-web-search-api-on-amazon-bedrock-agentcore/)。
此前AgentCore搜索主要通过Gateway暴露给MCP客户端；此次提供直接Web Search API，适合代码直接获取搜索结果而不额外建立Gateway及工具目标。**区别：** 11月6日报道的Web Answer是带引用的综合回答能力，不能把此次Web Search API当成同一条GA新闻重报。**风险：** 外部网页可能过时或包含提示词注入；搜索结果必须进行来源与时间核验。
### 2.3 AI-PDLC：六Agent产品研发前半程
**AWS｜2026-11-11｜新颖度5/5｜参考方案/教程，非通用GA。** [官方](https://aws.amazon.com/blogs/machine-learning/accelerating-product-development-with-ai-driven-lifecycle-management-ai-pdlc-in-aws-quick/)。
AWS Quick示例由一个Orchestrator协调五个专业Agent，在Discover、Decide、Design、Prototype阶段生成可审阅产物，随后交给编码Agent。每阶段设置人工批准门禁，记录决策与理由；可选择深度探索或快速路径。**借鉴：** 需求→验收条件→代码变更的可追溯性，比一次性让Agent自动实现所有功能更重要。文章所称提速是场景潜力，不是独立测量的普适收益。
### 2.4 AWS Emulator：Coding Agent的本地反馈环境
**AWS｜2026-11-11｜新颖度4/5｜工具发布。** [官方](https://aws.amazon.com/blogs/aws-insights/better-feedback-for-building-with-agents/)。
AWS介绍本地模拟环境，使开发者和Coding Agent能够用熟悉的AWS API、SDK与工具检查应用行为，而不必先创建云资源；所模拟操作不产生AWS服务调用费用。**限制：** 模拟器覆盖与云端真实行为可能存在差异，不能替代集成、性能、安全及真实权限测试。对银行外网开发/内网联调，可借鉴“本地Mock反馈→内网真实联调”两阶段验证。

## 5. Agent Ecosystem
**5.1 Agent Testing / Trace：** 把Dify、Java Capability和业务回读统一为`trace_id`、`session_id`、`capability_id`、`tool_args_hash`、`authorization`、`verified_effect`。框架变化不应迫使Golden Set重写。
**5.2 MCP / Tool Calling：** Web Search API说明并非每个工具都必须通过MCP；内部接口优先采用稳定API契约，只有跨Agent复用与标准发现需求明确时再包装MCP。外部网页数据不可信。
**5.3 Workflow / Browser Agent：** AI-PDLC人工审批与Emulator快速反馈可组合：先Mock验证执行计划，再在授权环境执行；Browser Agent的点击成功仍需业务状态回读。
**本周最值得体验：** 从两条Dify Mock执行记录生成统一AgentTrace，比较工具选择、参数和最终事实校验。
**Agent 实践启发：** 将“能运行”“答案正确”“业务有权限”“实际状态一致”拆为四道独立门禁。

## 7. 企业实践
**AWS UAEF跨行业应用（11/11）。** AWS称电信、医疗、金融服务等12家组织使用统一评估框架，对不同Agent版本进行质量比较。做法是统一执行轨迹、指标与实验存储；公开文章没有提供可独立验证的统一业务ROI。**借鉴：** 智能测试助手先用20条固定问句比较Dify工作流版本，不因切换模型或框架丢失历史基线。[来源](https://aws.amazon.com/blogs/machine-learning/uaef-a-framework-agnostic-system-for-closed-loop-evaluation-of-ai-agents/)。

## 8. 今日工具推荐
**UAEF**：[GitHub](https://github.com/awslabs/uaef)。重点研究GenericJSONAdapter、`tool_selection_accuracy`、`parameter_quality`与实验对比。先用脱敏JSON样本和确定性断言；不要直接将真实银行Trace送至外部评审模型或云端持久化。

## 9. 今日实战
**测试经理助手最小统一Trace契约：**
```json
{"trace_id":"mock-001","session_id":"s-001","capability_id":"query_execution_summary","expected_capability":"query_execution_summary","authorization":"ALLOW","tool_status":"SUCCESS","verified_effect":true,"workflow_version":"v1"}
```
示例为虚构数据。真实系统中`authorization`和`verified_effect`只能由可信Java服务及独立验证器产生。

## 10. Today Worth Thinking
**Agent版本升级后，回答更自然但工具选错一次、越权拦截失效一次，是否仍应发布？** 不应只看总分；关键权限和事实正确性应设置硬门禁，平均质量分仅作为辅助。

## 11. 30分钟 Action
0—10分钟准备两条执行统计、两条负责人查询和两条越权/参数错误的Mock问句；10—20分钟记录预期Capability、参数、权限结果和实际Trace；20—30分钟计算工具选择准确率、参数合规率与越权阻断率。**完成标准：** 6条全部留存可复现证据，任何越权放行判为阻断发布。

## 13. 我的备注：金融测试与智能测试平台
**测试经理智能助手：** 保持Vue3 iframe + Dify Chatflow + DeepSeek V4 + Java Capability API + PostgreSQL。短期先完成内网联调、执行统计/负责人查询、服务端权限和Golden Set；可把UAEF的统一Trace与回归对比思想落实到现有Java日志，不必引入Python/AWS依赖。为每次修改记录工作流版本、模型配置、接口版本、测试集版本和失败用例。
**日志脱敏检测平台：** 将规则扫描、AI精筛、人工复核、继续扫描与失败重扫的事件关联同一业务Trace，同时保留执行轮次和幂等键；任何新轮次不能被旧回调覆盖。
**Agent Testing指标：** Tool Selection Accuracy、Parameter Compliance、Unauthorized Call Block Rate、Verified Task Success、Trace Coverage、Regression Rate。**结论：** 可复用评估契约比某一个Agent框架更能保护长期投入。
