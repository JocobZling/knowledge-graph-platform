## 1. 今日摘要
重点是Agent权限默认值、失败关闭与Skill真实贡献评估。Claude Code 2.1.328增加云平台auto mode及MCP Hook失败阻断；SkillBuffBench提出三种Skill访问方式与记忆交叉评估；GitHub扩展OIDC审计流。三个独立技术主题，不凑四条。

## 2. AI/大模型 Top News
### 2.1 Claude Code 2.1.328（Anthropic，11/19，5/5）
[官方Release](https://github.com/anthropics/claude-code/releases/tag/v2.1.328)。Opus 4.6/Sonnet 4.6在Bedrock、Google Cloud Agent Platform、Microsoft Foundry及Claude apps gateway增加auto mode；未指定权限模式的相关交互会话默认进入该模式。MCP工具Hook可配置onFailure:block，调用失败时阻止动作；新增恢复延迟工具调用的宿主控制及遥测配置提示。属于权限行为变化而非普通小修复。auto mode不是无条件放行，亦不代表可离线运行。金融实践：审批服务故障应阻断写操作，恢复会话时重新验证授权。
### 2.2 SkillBuffBench（Dong等，11/17，5/5）
[原始预印本](https://arxiv.org/abs/2611.22017)。无Skill、人工选定Skill、自动发现Skill三种方式，交叉记忆开关、四种Harness及多种模型，以确定性验证器判分，同时独立记录成本、轮次、耗时。任务来自材料和生物领域。当前仅发布设计，实验尚未完成，不存在已证实的Skill提升数字。区别于此前Skill复用指南及Copilot Evals，研究对象是Skill的边际贡献与发现效果。
### 2.3 GHE.com审计流OIDC（GitHub，11/19，4/5）
[官方](https://github.blog/changelog/2026-11-19-s3-audit-log-streaming-with-openid-connect-expands-to-ghe-com/)。具备数据驻留能力的Enterprise Cloud可通过OIDC向S3传输审计日志，无需在GitHub保存长期AWS凭据。此前github.com已支持，新增为GHE.com覆盖。并非隔离内网GHES支持。借鉴短期身份、最小权限、审计传输故障检测。
第四条省略。

## 5. Agent Ecosystem
Skill与Harness：固定模型与任务，比较无Skill、人工指定、自动发现；再控制记忆变量，避免把模型差异归因于框架。
MCP/Tool Calling/安全：策略服务超时或Hook失败时，关键操作默认拒绝；恢复执行需检查审批时效。
Workflow/Browser Agent：页面点击和API写入采用同一服务端授权原则，恢复后核对任务所有权和真实结果。
**本周最值得体验：** Skill三组对照实验。
**Agent 实践启发：** 自动发现正确Skill与使用正确Skill是两个不同质量指标。

## 6. 开源推荐
[open-policy-agent/opa](https://github.com/open-policy-agent/opa)，约12.5k Stars（11/20页面舍入值），Apache-2.0。通用声明式策略引擎，使用Rego表达授权决策；适合独立验证Agent工具准入策略。成熟项目而非新发布。内网先审查依赖和部署许可，不要求引入生产。

## 7. 企业实践
GitHub将审计日志传输与长期云密钥解耦，通过OIDC实现短期认证。官方未公布泄露风险下降量化结果。借鉴：工具调用不持有管理员长期凭据，审计服务独立保存事件，凭据过期或权限收回后必须拒绝访问。

## 8. 今日工具推荐
OPA CLI，使用 opa test . 验证本地Mock策略；不部署服务也可编写授权测试。真实业务仍由Java执行层授权和验证。

## 9. 今日实战
设计Skill对照：同一执行统计Mock任务组，A无Skill，B人工指定，C自动发现；固定模型、数据和权限，分别记录业务正确率、Skill命中率（仅C）、工具调用数、耗时及越权。每组重复三次；样本太小仅作探索，不宣称统计显著。

## 10. Today Worth Thinking
如果人工指定Skill能通过测试，但自动发现经常选择错误Skill，问题可能是能力描述、检索、路由，而非Skill内容本身。应分别测试发现与执行。

## 11. 30分钟 Action
0—10分钟：选3条脱敏问句，定义预期工具及结果。
10—20分钟：运行无Skill、指定Skill、自动发现三组（可用Mock路由模拟）。
20—30分钟：对比结果与调用记录，标注发现失败、参数失败、执行失败。产出9条运行记录；若真实环境不可用明确标为模拟。

## 13. 我的备注
测试经理助手：主工程保持既有交付路径；探索工程用等价任务对比Dify、DSH、LangGraph等候选，固定模型入口、Java API与数据，分别记录能力发现及执行失败。不为实验绕过内网模型调用限制。
日志脱敏平台：AI精筛失败与规则扫描完成分别记录；安全检查不可用不能判为无风险；样本回归按规则、Prompt和模型版本分层。
Agent Testing：新增Skill发现准确率、指定Skill条件成功率、策略故障阻断率、恢复授权一致性；对关键权限失败设硬门禁。
结论：先验证新增Skill是否真的改善任务，再扩大能力库；权限决策不能随模型或Harness变化而失效。
