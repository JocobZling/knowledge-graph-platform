## 2. AI / 大模型 Top News
### 2.1 自动化安全研究：Linux 内核问题从候选发现走向动态复现和候选修复
**主体：OpenAI｜2026-11-04｜新颖度 5/5｜研究/工程披露，非新模型 GA。**  
官方：https://openai.com/index/a-thousand-fewer-paths-to-root/

OpenAI 披露受控研究环境中的自动化流水线：选择高价值代码范围、静态审查、隔离环境动态复现、验证安全影响、生成候选补丁，最后交由人类研究人员复核。一次研究筛选出 2,308 个候选发现，动态复现 1,724 个，报告 948 个独立本地提权问题及对应候选补丁；整个研究运行的 API 费用约 121 万美元。**必须区分：候选发现、动态复现、独立漏洞、候选补丁和上游接受修复是不同统计口径。** 这不是对所有 Linux 系统的普遍漏洞率测量。对金融测试的借鉴是将 AI 扫描结果与复现、人工审核、修复和同条件复测分别记录；不把“模型认为已修复”当作关闭依据。

### 2.2 Images 2.6：更快生成、GIF 与更精细的编辑 API
**主体：OpenAI｜2026-11-04｜新颖度 5/5｜正式产品发布。**  
官方：https://openai.com/index/introducing-images-2-6/

Images 2.6 在 ChatGPT、Codex 和 API 推出。官方报告生成速度比之前提高约 50%；API 提供 Flare 与 Sunburst 两种选择。新增 GIF 动画生成、API 图像标记编辑、SVG 导出，以及独立于画质的复杂度参数。对海报、产品图、UI 示意图有实际价值；但**不能据此保证中文字符零错别字或编辑时所有原文字形保持不变**。建议针对中文标题、数字、品牌元素、局部修改和多轮编辑建立视觉回归集。

**第三、第四条：** 最近24小时及回溯窗口内未核验到符合去重与重要性标准的另外两条独立高价值新闻，不以旧内容补足。

## 5. Agent Ecosystem
**5.1 Agent / Workflow：** 将安全检测拆为候选发现、可复现验证、修复建议、人工批准、复测与关闭。每一步保留版本、证据和独立状态；重试不能产生重复副作用。  
**5.2 Skill / MCP / Tool Calling：** 工具是否允许执行应由可信服务控制；模型输出的“已验证”不构成证据。对 MCP 工具返回内容执行 Schema 校验、资源授权与异常处理。  
**5.3 Browser Agent / 多模态：** 图像编辑成功不等于中文文字准确；浏览器操作成功也不等于后台数据正确。应结合视觉差异检查、文本人工核验和业务接口回读。

**本周最值得体验：** 以一组脱敏扫描结果构造“模型认为风险已修复，但同条件复扫仍命中”的 Mock 场景，验证平台是否阻止关闭。  
**Agent 实践启发：** Agent 的最终声明应弱于独立复现与业务状态证据；“找到”“修好”“验收通过”必须分开记录。

## 9. 今日实战
**建立“扫描结果—整改—复扫”证据契约。**
```json
{
  "finding_id": "mock-001",
  "rule_version": "v1",
  "prompt_version": "p1",
  "scan_epoch": 3,
  "human_review": "CONFIRMED",
  "fix_status": "PROPOSED",
  "rescan_epoch": 4,
  "rescan_result": "STILL_DETECTED",
  "closure_allowed": false
}
```
以上为模拟数据。关键约束：整改状态和复扫状态由可信后端更新；旧轮次回调不得覆盖新轮次。

## 10. Today Worth Thinking
> 当 AI 提交了一份看起来合理的修复建议，但无法在受控环境中复现原问题，是否应将该问题标记为已修复？

不应直接关闭。至少区分“无法复现”“已修复”“误报”“待人工复核”，并保存测试环境、版本和证据。否则会把证据缺失误记为质量提升。

## 13. 我的备注：金融测试、Agent Testing 与智能测试平台
**测试经理智能助手：** 保持 Vue3 iframe → Dify Chatflow → DeepSeek V4 → Java Capability API → PostgreSQL 的轻量一期路线。优先完成执行统计、负责人查询的权限与事实校验；后续写入操作再引入审批、幂等和副作用回读，不因为安全研究新成果改造整体架构。  
**日志脱敏检测平台：** 优先把“失败重扫/继续扫描”的执行轮次与证据链打通，规则扫描和 AI 精筛分别保留状态；同条件复扫成功才允许关闭真实风险。  
**Agent Testing：** 重点统计 Verified Finding Rate、Fix Verification Rate、Critical False Negative、Stale Callback Rejection Rate。安全 Agent 的“发现数量”不是唯一价值指标。

**今日结论：** 可信自动化不是让 Agent 自行宣告完成，而是让每个关键状态都能由独立证据验证。
